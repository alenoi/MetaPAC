## Added publications

### MXSens: Sensitivity-Aware Mixed-Precision Quantization for Efficient LLM Inference

Simla Burcu Harma, Danila Mishin, Zhengyuan Su, Ayan Chakraborty, Elizaveta Kostenok, Dongho Ha, Babak Falsafi, Martin Jaggi, Yunho Oh, Amir Yazdanbakhsh. arXiv:2607.17733, 2026-07-20. https://arxiv.org/abs/2607.17733

MetaPAC relevance: MXSens is a strong adaptive-allocation baseline because it measures non-uniform layer- and column-wise quantization sensitivity and maps that sensitivity to 4/6/8-bit mantissa choices. Its microscaling-aware formulation also provides an explicitly hardware-efficient alternative to a generic importance-to-action mapping.

### ScaleBITS: Scalable Bitwidth Search for Hardware-Aligned Mixed-Precision LLMs

Xinlin Li, Timothy Chou, Josh Fromm, Zichang Liu, Yunjie Pan, Christina Fragouli. arXiv:2602.17698, 2026-02-06. https://arxiv.org/abs/2602.17698

MetaPAC relevance: ScaleBITS combines sensitivity analysis with hardware-aligned block partitioning, bidirectional channel reordering, and constrained global bitwidth optimization. It is a useful baseline for separating the value of MetaPAC's importance predictor from the quality of the downstream budget/allocation mechanism.

## Important direction changes

The literature graph increasingly separates adaptive compression into two distinct technical problems: estimating local sensitivity and solving the global allocation problem under resource constraints. MXSens strengthens the fine-grained sensitivity branch, while ScaleBITS strengthens the hardware-constrained global allocation branch. This distinction is directly useful for future MetaPAC ablations because predictor quality and allocator quality should be evaluated independently.

## Baseline / competitor assessment

MXSens is a direct mixed-precision allocation baseline for MetaPAC's quantization branch. ScaleBITS is particularly important as an allocator baseline because its constrained global optimization and hardware-aligned partitioning test whether a learned importance score requires a stronger downstream allocation solver than clustering-based zoning.
