# MetaPAC literature watch — 2026-08-31

This run expanded the canonical MetaPAC literature collection using both keyword-based discovery and graph-style expansion from previously retained papers and their adjacent method families. Deduplication was performed by DOI/arXiv identifier and normalized title before inclusion.

## Changes

Five publications were added and ten new search terms were added to the keyword collection.

The strongest new direct comparison is GAMMA, which learns module-wise precision preferences for mixed-precision quantization while explicitly considering cross-module interactions and exact deployment budgets. This is closely aligned with MetaPAC's adaptive action-allocation problem, although GAMMA optimizes precision only rather than mixed pruning/quantization actions.

SNIPER is a strong pruning-allocation baseline because it converts fixed importance estimates into depth/width pruning decisions under an exact compression budget using binary knapsack optimization. It is particularly relevant for separating the quality of MetaPAC's importance predictor from the quality of its downstream action allocator.

SHIFT-LLM introduces training-free distribution-shift correction after depth pruning through calibrated linear residual adapters. This is relevant to the MetaPAC recovery stage because it provides an alternative to recovery fine-tuning and knowledge distillation.

HyQuant introduces signal-guided hybrid precision inside attention, preserving selected accuracy-critical token regions at high precision while quantizing the rest. This broadens the search graph from layer/channel/neuron-level precision allocation toward dynamic state- and attention-pattern-level importance signals.

Compression Trinity combines sparsity, quantization, and low-rank approximations in a unified compression/recovery view. It is not a direct MetaPAC baseline in its current form, but it is relevant to future extension of the action space beyond keep/quantize/prune and to low-rank recovery mechanisms.
